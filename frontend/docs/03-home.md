# 首頁

## 目的

提供一般使用者查詢 ISO 文件。

## Layout

- 不使用 Sidebar。
- 使用 Table 顯示 ISO 文件。
- 支援分頁。
- 支援動態查詢。

## 主文件 Table

欄位：

| 欄位 | 說明 |
|---|---|
| 生效狀態 | 顯示文件目前狀態 |
| 文件編號 | 點擊後展開或收合附件清單 |
| 名稱 | 點擊後檢視主文件 |
| 頁數 | 主文件頁數 |
| 版本 | 主文件版本 |
| 發行日期 | 文件發行日期 |
| 生效日期 | 文件生效日期 |
| 公司別 | 文件所屬公司 |
| 備註 | 文件備註 |

## Row Expand

文件編號具有展開行為。

```text
主文件 Row
└─ Attachment Table
```

範例：

```text
HR-Gn-01 人事管理辦法
└─ HR-Gn-01-01 請假申請表
```

## 附件 Table

欄位：

| 欄位 | 說明 |
|---|---|
| 附件狀態 | 顯示附件目前狀態 |
| 附件編號 | 附件識別編號 |
| 附件名稱 | 點擊後下載附件 |
| 生效日期 | 附件生效日期 |

## 文件操作

### 主文件名稱

點擊名稱時：

- 開啟或檢視主文件。
- 不觸發附件 Row 展開。

### 文件編號

點擊文件編號時：

- 展開附件 Table。
- 再次點擊收合。

### 附件名稱

點擊附件名稱時：

- 下載附件。

## 查詢

首頁需提供動態查詢。

查詢條件目前尚未完全定義，實作時應參考 `[未完善]-api-contract.md`。

## Pagination

採 Server-side pagination。

前端至少需要管理：

```ts
page
pageSize
search
```

查詢條件改變時，page 應回到第一頁。
