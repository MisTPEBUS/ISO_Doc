# [未完善] ISO 文件維護

## Route

```text
/admin/documents
```

## 目的

管理 ISO管理程序、版本與表單及附件。

## 已知概念

```text
Document
├─ Current Version
├─ Versions[]
└─ Attachments[]
   └─ Attachment Versions[]
```

ISO管理程序與表單及附件皆有實體檔案，但**檔案可稍後補上**：

- ISO管理程序版本可先建立（不含 PDF），狀態為 `DRAFT`，補檔後轉 `PUBLISHED`。
- 表單及附件可先建立（僅表單及附件編號 + 名稱），檔案稍後上傳。
- 表單及附件為選配：一個版本可以沒有表單及附件。
- 表單及附件檔案可一次上傳多個。

## ISO管理程序已知欄位

- 生效狀態
- 文件編號
- 名稱
- 頁數
- 版本
- 發行日期
- 生效日期
- 公司別
- 備註

## 表單及附件已知欄位

- 表單及附件狀態
- 表單及附件編號
- 表單及附件名稱
- 生效日期

## 建議管理功能

- 新增ISO管理程序
- 編輯ISO管理程序基本資料
- 建立新版本（可先不上傳 PDF，預先建立 `DRAFT`）
- 上傳 / 補上ISO管理程序 PDF（`DRAFT` → `PUBLISHED`）
- 預先建立表單及附件（僅表單及附件編號 + 名稱，尚無檔案）
- 批次上傳多個表單及附件檔（單次選取多個檔案）
- 為預先建立的表單及附件補上檔案
- 更新表單及附件
- 建立表單及附件新版本
- 檢視歷史版本

## 已定案（依 SPEC.md 第 4、5 節）

- 表單及附件為選配，一個版本可 0..N 個表單及附件。
- ISO管理程序版本與表單及附件皆可「先建中繼資料、後補檔」。
- 表單及附件檔案單次可上傳多個，批次全有全無（任一檔驗證失敗整批退回）。
- 每個表單及附件的編號 / 名稱由前端逐檔提供，後端不自動產生。
