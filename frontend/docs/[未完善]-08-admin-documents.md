# [未完善] ISO 文件維護

## Route

```text
/admin/documents
```

## 目的

管理 ISO 主文件、版本與附件。

## 已知概念

```text
Document
├─ Current Version
├─ Versions[]
└─ Attachments[]
   └─ Attachment Versions[]
```

主文件與附件皆有實體檔案，但**檔案可稍後補上**：

- 主文件版本可先建立（不含 PDF），狀態為 `DRAFT`，補檔後轉 `PUBLISHED`。
- 附件可先建立（僅附件編號 + 名稱），檔案稍後上傳。
- 附件為選配：一個版本可以沒有附件。
- 附件檔案可一次上傳多個。

## 主文件已知欄位

- 生效狀態
- 文件編號
- 名稱
- 頁數
- 版本
- 發行日期
- 生效日期
- 公司別
- 備註

## 附件已知欄位

- 附件狀態
- 附件編號
- 附件名稱
- 生效日期

## 建議管理功能

- 新增主文件
- 編輯主文件基本資料
- 建立新版本（可先不上傳 PDF，預先建立 `DRAFT`）
- 上傳 / 補上主文件 PDF（`DRAFT` → `PUBLISHED`）
- 預先建立附件（僅附件編號 + 名稱，尚無檔案）
- 批次上傳多個附件檔（單次選取多個檔案）
- 為預先建立的附件補上檔案
- 更新附件
- 建立附件新版本
- 檢視歷史版本

## 已定案（依 SPEC.md 第 4、5 節）

- 附件為選配，一個版本可 0..N 個附件。
- 主文件版本與附件皆可「先建中繼資料、後補檔」。
- 附件檔案單次可上傳多個，批次全有全無（任一檔驗證失敗整批退回）。
- 每個附件的編號 / 名稱由前端逐檔提供，後端不自動產生。
